notice.js

Tiny, dependency-free toast notifications. Typed, accessible, and safe by default.

TypeScript 0 dependencies < 4 kB JS gzipped ARIA live regions XSS-safe text 
npm install notice.js

Types

Each type sets its own ARIA role: errors and warnings are announced immediately.

NoticeJs.success('Profile saved');
new NoticeJs({ title: 'Heads up', text: 'Disk almost full', type: 'warning' }).show();

Positions

Nine corners and edges, plus full-width top and bottom bars.

Promises

Show a loading notice that becomes a success or error notice when the work finishes.

await NoticeJs.promise(saveProfile(), {
  loading: 'Saving…',
  success: (user) => `Saved ${user.name}`,
  error: (err) => ({ title: 'Save failed', text: err.message }),
});

Actions

Buttons inside the notice, for undo and retry flows.

new NoticeJs({
  text: 'Email archived',
  actions: [{ label: 'Undo', onClick: () => restoreEmail() }],
}).show();

Timing

Hover, focus or switch tabs and the countdown pauses. On touch screens, swipe a notice away.

new NoticeJs({ text: 'Back in 5', timeout: 5000 }).show();
new NoticeJs({ text: 'I stay', timeout: false }).show();
NoticeJs.closeAll();

No duplicates

Give a notice an id, and showing it again updates the visible one instead of stacking a copy.

new NoticeJs({ id: 'offline', text: `Offline (retry ${n})`, type: 'warning' }).show();

Safe HTML

text is always plain text. Rich content goes through html, with an optional sanitizer such as DOMPurify.

new NoticeJs({ text: userInput }).show();   // never parsed as HTML
new NoticeJs({ html: markup, sanitize: DOMPurify.sanitize }).show();

More options

Modal overlay, right-to-left text, custom animations, and theming with CSS variables.

:root {
  --noticejs-success-bg: #0f766e;
  --noticejs-success-accent: #115e59;
  --noticejs-radius: 12px;
}
